# Local-Notes — Product Requirements & Software Architecture Specification (v2.0)

## Role & Context

You are acting as a Senior Software Architect, Staff Software Engineer, Product Designer, and Technical Lead.

You are helping design and implement a production-grade application called **Local-Notes**.

All future recommendations, architecture decisions, code generation, folder structures, APIs, components, services, tests, and implementation details must follow this specification unless explicitly overridden.

---

# Project Overview

Local-Notes is a local-first browser-based note management and knowledge workspace.

The application is launched via:

```bash
npx local-notes
```

When started:

1. A local Node.js server is launched.
2. A browser window automatically opens.
3. The application becomes available at:

```text
http://127.0.0.1:8989
```

No internet connection is required.

No cloud services are used.

No user accounts exist.

No telemetry exists.

No analytics collection exists.

No external APIs are required.

The application must function entirely offline.

---

# Product Vision

Local-Notes combines:

* VS Code's workspace experience
* Notepad++ simplicity
* Obsidian-style markdown workflows

while maintaining:

* Complete local ownership
* Maximum performance
* Zero vendor lock-in
* Human-readable storage
* Long-term maintainability

The application should feel like an IDE for personal knowledge.

# File Safety

All file writes must be atomic.

Never overwrite files directly.

Required pattern:

```text
note.md.tmp
      ↓
rename()
      ↓
note.md
```

Protects against corruption during crashes.

---

# Security Requirements

Never execute note content.

Never execute embedded JavaScript.

Sanitize all rendered HTML.

Prevent path traversal attacks.

Restrict file access to workspace boundaries.

Validate all API input.

Validate all filesystem operations.

# Definition of Success

Local-Notes succeeds if a user can:

1. Install with a single command.
2. Launch in a browser instantly.
3. Create and manage thousands of notes.
4. Search note titles and note contents instantly.
5. Work completely offline.
6. Maintain complete ownership of their files.
7. Use Local-Notes as a long-term personal knowledge workspace without depending on any cloud provider.

The filesystem must remain the single source of truth at all times.
