# Product

## Register

product

## Users

Individual knowledge workers using Local-Notes in desktop or laptop browsers. Primary workflow: discover, search, read, and edit local notes for extended focused sessions. Users expect familiar native desktop-tool behavior, dense information, predictable keyboard interaction, and complete local ownership.

## Product Purpose

Provide fast, private, filesystem-first knowledge workspace that works offline after installation. Files remain ordinary Markdown and plain text. Interface should disappear into note work, scale to large collections, and protect content during crashes or external file changes.

## Brand Personality

Focused, calm, native.

## Anti-references

- Neon cyberpunk styling
- Glassmorphism
- Oversized SaaS cards
- Decorative gradients
- Excessive or ornamental animation
- Marketing-page patterns inside application workspace
- Unfamiliar controls replacing standard desktop affordances

## Design Principles

- Notes remain primary visual focus.
- Familiar desktop-tool patterns beat novelty.
- Dense information stays calm through hierarchy and spacing.
- Dark surfaces reduce glare without collapsing contrast.
- Motion communicates state only.

## Accessibility & Inclusion

- WCAG 2.1 AA target
- Complete keyboard operation for MVP workflows
- Visible focus, semantic labels, screen-reader support, and high-contrast states
- Reduced-motion preference respected
- Color never serves as sole state indicator
